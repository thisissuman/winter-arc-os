## Approved direction

Calm charcoal/violet and Geist-like type; narrow readable content, spacious rows with quiet dividers, very few surfaces, large completion controls. Today has no tracking forms/dashboard. Routine creation has only name/schedule. History is an individual calendar, not a wide multi-habit matrix. Destructive Settings controls remain a disclosure.

The boards use sample states and dates to show interaction moments, not a synchronized performance dataset. Final semantic controls, focus behavior, responsive dimensions, light theme, edge states, privacy, and consistency calculations must follow canonical docs and tests even where raster rendering varies.
